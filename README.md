# Applied Data Science Blueprint

Welcome to the Data Science Blueprint repository. This project serves as a structured, production-ready reference guide for foundational data science and feature engineering workflows. 

---

## 🗺️ Repository Roadmap

This repository is split into distinct modules covering the lifecycle of data preparation and exploration:

1. **[Exploratory Data Analysis (EDA) Guide](./eda-guide.md)**
   * Core objectives: Data collection, cleaning, profiling, and visualisation.
   * Statistical characteristics of numerical and categorical variables.
   * Outlier detection via Z-Score, IQR, and visual plots.
   * Multivariate analysis and automated EDA tool profiles.

2. **[Categorical Encoding Guide](./ENCODING.md)**
   * Strategic implementations of One-Hot, Label, and Ordinal encoding.
   * Algorithmic considerations and avoidance of artificial order.
   * Advanced transformation techniques including binning and rare category grouping.
  
3. **[Feature Scaling Guide](./feature-scaling.md)**
   * Mathematical workflows of Standardisation vs. Min-Max Normalisation.
   * Algorithmic impact on distance-based and gradient descent architectures.
   * Criteria for scale-invariance in tree-based models.


---

## 🛠️ Built With

* **Languages:** Python 3.x
* **Core Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn

## 🚀 Getting Started

### Prerequisites
Ensure you have Python installed, then set up the required dependencies:
```bash
pip install pandas numpy scikit-learn matplotlib seaborn
```

### Usage
Navigate to the individual markdown files linked in the roadmap above to review theoretical frameworks, implementation best practices, and statistical guidelines.
